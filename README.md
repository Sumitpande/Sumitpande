## About Me

I'm a software engineer with **4+ years of experience** building backend-heavy full-stack applications, currently working on enterprise-scale platforms. I design and ship **REST and GraphQL APIs**, work across **Node.js, React, and Vue** ecosystems, and build data layers on **PostgreSQL, MongoDB, and Redis**.
